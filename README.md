# 🏥 PT 시뮬레이션 병원 — 프로토타입

신성대학교 물리치료학과 학생을 위한 **시뮬레이션 기반 임상 학습 게임**입니다.
학생은 치료사가 되어 병원을 돌아다니며 환자를 **SOAP**로 평가하고 적절한 중재를 선택합니다.
문항은 국가고시형 **5지선다 긍정형**이며, 40문항 중 **70점 이상이면 합격**, 실패하면 재도전할 수 있습니다.

| 층 | 공간 | 내용 |
|---|---|---|
| 1F | 임상의사결정 문진실 | 문진(S) → 검사(O) → 평가(A) → 의뢰·계획(P), 적색신호·감별 |
| 2F | 운동치료실 | 정형·신경계 재활 운동 처방, 단계 진행 기준 |
| 3F | 소아물리치료실 | 뇌성마비 유형(경직형·운동이상형·운동실조형), 증후군, 발달지연 |
| 4F | 물리적인자치료실 | 전기·광선·열·수치료 선택, 매개변수, 금기 |

- 층마다 **5개 병실에 랜덤 환자**가 배정되고(층당 20개 케이스 풀, 총 80케이스 480문항 · 케이스당 6문항 중 방문마다 2문항 출제), 환자마다 평가 1문항 + 중재 1문항이 출제됩니다.
- 홈에서 **내 과목**(층)을 고르면 그 층의 평가·연습을 바로 시작할 수 있고(학생별로 기억), 병원 안에서는 **층 이동** 버튼으로 어느 층이든 바로 갈 수 있습니다. 종합 순회(4층 × 5명 × 2문항 = 40문항)도 그대로 제공됩니다.
- **AI 튜터(Gemini)**: 오답 시 자동 상세 해설(설정으로 항상/수동 전환), 해설에 이어지는 후속 질문, 문진 단계에서 **AI 환자에게 자유 질문**, 결과 화면의 **AI 학습 코치**. 키가 없으면 이 기능들만 조용히 꺼집니다.
- 용어는 **대한의학회 의학용어집 6.1판 신용어** 기준으로 작성했습니다. 색상은 신성대학교 그린 테마입니다.
- 휴대폰·맥·PC 모두 브라우저에서 동작(PWA, 홈 화면 추가 가능). 모바일은 터치 D패드/탭 이동.

## 폴더 구성

```
01_AI 학습앱/
├─ start.bat / start.command   ← 더블클릭 실행(Windows / Mac)
├─ app/                        ← 웹앱 본체(정적 파일, 그대로 배포 가능)
│  ├─ index.html, css/style.css
│  └─ js/
│     ├─ data/parts/*.js       ← ★ 케이스 원본(여기서 편집)
│     ├─ data/cases_Nf.js      ← 빌드 결과(자동 생성, 직접 수정 X)
│     ├─ hospital.js           ← 병원 지도(캔버스, 이동/엘리베이터)
│     ├─ session.js            ← SOAP 흐름·문항·채점
│     ├─ patient.js            ← 침대 위 환자 SVG(부위 표시, 장비 적용)
│     ├─ gemini.js             ← AI 튜터·사례 생성
│     ├─ admin.js              ← 승인·성적·엑셀·설정
│     └─ storage.js            ← 로컬/서버 저장소 어댑터
├─ server/server.js            ← 선택형 Node 서버(계정 승인 공유, CSV 기록, Gemini 키 보호)
├─ server/config.example.json  ← 서버 설정 예시(복사해서 config.json)
├─ tools/build_cases.js        ← parts → cases_Nf.js 빌드+검증
├─ tools/cases_to_md.js        ← 케이스 → Obsidian 노트(케이스_노트/)
└─ 케이스_노트/                 ← 임상 사례 연구 형식의 마크다운 80건 + 색인
```

## 실행 방법

### A. 교수님 PC에서 서버로 실행(권장 — 여러 기기에서 같은 계정/성적 공유)
1. `start.bat`(Windows) 또는 `start.command`(Mac) 더블클릭. 브라우저가 `http://localhost:8787` 로 열립니다.
2. 터미널에 표시되는 **같은 Wi-Fi 기기용 주소**(예: `http://192.168.0.10:8787`)를 학생에게 알려주면 폰·노트북에서 접속됩니다.
3. 학생은 **학번·이름·숫자 비밀번호**로 가입 신청 → 교수님이 **관리자 콘솔 → 승인 관리**에서 승인.
4. 결과는 `server/data/results.json`, `server/data/results.csv`(엑셀에서 바로 열림)에 자동 기록되고, 관리자 콘솔에서 **.xlsx 다운로드**도 가능합니다.

관리자 PIN 기본값은 `1234` 입니다. `server/config.json` 에서 꼭 바꾸세요.

### B. 서버 없이 정적 파일로 사용(GitHub Pages 등 무료 배포)
**배포 주소: https://inr1265-oss.github.io/pt-sim-hospital/** (저장소 inr1265-oss/pt-sim-hospital, main 에 push 하면 .github/workflows/pages.yml 이 pp/ 을 자동 배포)

`app/` 폴더를 그대로 업로드하면 됩니다. 이 경우 계정·성적은 **각 브라우저(localStorage)** 에 저장되므로
- 승인: 학생 기기에서 관리자 PIN을 입력해 승인하거나(처음 입력한 PIN이 그 기기의 관리자 PIN이 됨),
- 성적 수집: 학생이 결과 화면의 **"내 결과 엑셀 저장"** 으로 받은 파일을 제출하는 방식이 됩니다.
PC Chrome/Edge에서는 관리자 콘솔 → 성적 관리에서 **"결과 자동 저장 폴더 지정"** 을 하면 새 결과마다 지정 폴더의 `PT_시뮬레이션_성적.xlsx` 가 자동 갱신됩니다.

### 개인정보
저장 항목은 학번, 이름, 비밀번호의 SHA-256 해시, 성적뿐입니다. 전화번호·이메일은 받지 않고, 서버 모드의 데이터는 교수님 PC(`server/data/`)에만 남습니다. 외부 전송은 Gemini 호출(문항·사례 텍스트만) 외에는 없습니다.

## Gemini(무료 AI) 연동
1. [Google AI Studio](https://aistudio.google.com/) 에서 무료 API 키 발급.
2. **서버 모드**: `server/config.json` 의 `geminiApiKey` 에 입력(키가 브라우저에 노출되지 않음). 모델명은 `geminiModel`(기본 `gemini-2.5-flash`, 최신 무료 모델명은 AI Studio에서 확인).
3. **정적 모드(이 브라우저만)**: 관리자 콘솔 → 설정 → Gemini API 키 입력(그 브라우저에만 저장).
4. **정적 배포에서 모든 학생에게 켜기(GitHub Pages)**: `app/js/config.js` 의 `geminiKey` 에 키를 넣고 push. 이때 키는 반드시 [Google Cloud 콘솔 > 사용자 인증 정보](https://console.cloud.google.com/apis/credentials) 에서 **애플리케이션 제한사항: 웹사이트** 로 `https://inr1265-oss.github.io/*` 만 허용하도록 제한하세요. 무료 등급은 분당·일일 호출 한도가 있으므로 관리자 설정의 "AI 튜터 동작 방식"은 **오답일 때 자동**(기본)을 권장합니다. 같은 문항·같은 오답의 해설은 브라우저에 캐시되어 재호출하지 않습니다.
4. 기능: 오답/정답 해설 후 **"AI 튜터에게 더 자세히 묻기"**, 관리자 콘솔 **"AI로 새 환자 사례 생성"**(JSON 스키마 검증 후 케이스 풀에 추가).

## 케이스 추가·수정(Obsidian 연동)
- 원본은 `app/js/data/parts/pN_xx.js` 입니다. 전기치료 교재의 사례를 같은 형식(S 채팅 5개 / O 검사 6개 / A ICF 3행 / P / 문항 4개: A단계 2 + P단계 2)으로 추가하세요. 기존 케이스에 문항만 더하려면 `parts/q_extra_Nf.js` 처럼 케이스 id로 찾아 `Q`에 push 합니다(파일명이 `p`보다 뒤에 오도록 `q_`로 시작).
- 빌드·검증·노트 생성:
  ```bash
  node tools/build_cases.js && node tools/cases_to_md.js
  ```
- `케이스_노트/` 에 교재의 "임상 사례 연구" 형식(과거력 → 평가와 측정 → ICF 평가와 목표 → 중재 → 문항)으로 노트가 생성되어 Obsidian에서 바로 열람·링크할 수 있습니다.
- 정답 위치는 앱에서 매번 섞이므로 parts 파일에서 `answer`는 어느 인덱스여도 됩니다.

## 2026-10-20 업데이트: 문항 수·대화형 S/O·3D 보기
- **A/P 다문항**: 환자 1명당 평가(A) 3문항 + 중재(P) 3문항이 순서대로 출제됩니다(관리자 설정 "환자당 단계별 문항 수"로 1~5 조정). 종합 순회에서는 40문항에 맞춰 층마다 배정되는 병실 수를 자동 계산합니다.
- **대화형 문진·검사(LLM)**: Gemini 키가 있으면 S 단계에서 환자에게 자유 질문, O 단계에서 "자유 검사" 입력창에 시행할 검사를 적으면 사례와 일치하는 결과를 AI가 보고합니다(목록 검사와 일치하면 해당 카드도 자동으로 열림). 키가 없으면 기존 칩·카드 방식으로 동작합니다. 모델명은 설정에서 바꾸며(기본 `gemini-2.5-flash`), 존재하지 않는 모델명이면 자동으로 2.5-flash 로 재시도합니다.
- **3D 보기**: 병원 화면 상단의 **🧊 3D 보기** 버튼으로 Three.js 기반 입체 병원으로 전환합니다(조작·규칙은 2D와 동일, 방향키·클릭·D패드). 인터넷이 없어 Three.js를 못 받으면 자동으로 2D로 돌아갑니다.
- **환자 이름**: 소아 환자도 성인과 같은 세 글자 성명으로 통일했습니다.

## 2026-10-20 업데이트 2: 1인칭 3D 병원(2D 지도 제거)
- 병원 화면은 **치료사 1인칭 3D**만 사용합니다(`app/js/hospital3d.js`, Three.js r128 CDN). 2D 지도(`hospital.js`)는 제거했습니다.
- 조작: ↑↓(W/S) 걷기, ←→(Q/E) 돌기, A/D 옆걸음, 화면 드래그로 둘러보기, D패드(모바일). 복도 바닥이나 병실을 클릭하면 자동으로 걸어가며, 병실을 클릭하면 침대 발치까지 이동합니다.
- **진료 시작**: 침대에 있는 3D 환자를 클릭(또는 Enter)하면 환자 차트(SOAP)가 열립니다. 병실은 01호부터 **순서대로**만 진료할 수 있고, 문 위 라벨에 "▶ 지금 진료할 환자"가 표시됩니다.
- 환자 모델은 케이스에 따라 달라집니다: 자세(바로누움 / 엎드림 / 침대 가장자리에 앉음 — 어깨·팔꿈치·손목·손·목·머리 문제나 1층 문진 환자는 앉은 자세), 성별(머리 모양·소아 환자복 색), 연령(노인은 회색 머리·안경, 영유아는 작은 체구). 누운 환자는 환부 위치에 빨간 고리가 맥동합니다.

## 2026-10-20 업데이트 4: VR 교육 시뮬레이션 스타일
